# 🌦️ Weather Forecast Website

A modern, responsive weather forecasting web application built using **React, TypeScript, and Vite**. It provides real-time weather information, city search functionality, and weather alerts through a clean and user-friendly interface.

## ✨ Features

- 🌍 **City Search:** Search for weather information by city name.
- 🌡️ **Real-Time Weather:** View current weather conditions and temperature.
- 🌧️ **Weather Alerts:** Access weather alerts where supported by the data source.
- 📱 **Responsive Design:** Works across desktops, tablets, and mobile devices.
- ⚡ **Fast Performance:** Powered by Vite for a fast development experience.
- 🎨 **Modern Interface:** Clean and intuitive user interface.

## 🛠️ Technologies Used

- **React** – Building the user interface.
- **TypeScript** – Type-safe JavaScript development.
- **Vite** – Fast development server and build tool.
- **CSS** – Styling and responsive layouts.
- **Weather API** – Fetching weather data, depending on the configured provider.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following software:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (included with Node.js)
- [Git](https://git-scm.com/) (optional, for cloning the repository)

### 1. Clone the Repository

```bash
git clone https://github.com/h38680158-eng/weather-forecast-website.git
```

### 2. Navigate to the Project Folder

```bash
cd weather-forecast-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔐 API Configuration

If the application uses a third-party weather API, configure its API key according to the provider's instructions and the application's existing code.

**Important:** Never commit private API keys or other secrets to a public repository. For frontend applications, remember that environment variables exposed to client-side code are not truly secret.
